# Fond de carte

`communes-benin.geojson` : les 77 communes du Bénin, geoBoundaries `gbOpen/BEN/ADM2`, **domaine public**
(source : Map Maker Ltd., Stanford Earthworks, catalogue `stanford-rq343zx0554`).

`pnpm carte` en tire `src/domain/carte-benin.ts` : simplification qui garde les frontières partagées, projection, tracés SVG.
